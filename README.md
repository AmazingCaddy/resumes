# Resumes

This repository keeps the original LaTeX resumes and the new Typst migration.

## Typst files

- `Wenbin Wang-zh.typ`: rewritten Chinese resume in Typst, with a placeholder for 2024-present experience.

## Build

Install Typst first:

```sh
brew install typst
```

Compile the Chinese resume:

```sh
typst compile 'Wenbin Wang-zh.typ' 'Wenbin Wang-zh.pdf'
```

Watch while editing:

```sh
typst watch 'Wenbin Wang-zh.typ' 'Wenbin Wang-zh.pdf'
```

## 2024-present content checklist

To complete the new section, collect the following facts:

- Company or project name
- Role title
- Start and end dates
- Team size or collaboration model
- Main products or systems delivered
- Key technical decisions
- Quantified outcomes, such as users, customers, cost reduction, revenue impact, latency, reliability, or delivery speed
- Technology stack
